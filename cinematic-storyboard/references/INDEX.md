# Cinematic Storyboard Knowledge Graph

Camera is language. The [[shot-ladder]] is grammar. A PDF is canon for look, not an excuse to jump rungs — see [[pdf-import]]. Frames are written last, with [[prompt-craft]].

## Core

- [[shot-ladder]] — rungs 0–9, one-step rule, when a jump is justified
- [[pdf-import]] — extract text, empty ChatGPT exports, IP-heavy bibles, remapping
- [[prompt-craft]] — identity lock, size language per rung, continuity of frames

## Typical paths

1. Scene or script → [[shot-ladder]] then [[prompt-craft]]
2. Attached PDF → [[pdf-import]] then [[shot-ladder]] (reboard illegal calls)
3. Generate art → [[prompt-craft]] and [[imagine:]]

## Cross-skill

- [[imagine:]] — image/video generation after the board is legal
- [[xai-api:]] — in-app Grok + Imagine
- [[design-ui:]] — studio chrome around the board
