# Solari Cinematic Skills (Grok Ask)

Original Solari cinematic production skills for **Grok Ask**.

Keep **Sunwell** and **Moonwell**. Do not clone Warcraft / StarCraft / Marvel casts.

| Skill | Slash | Job |
| --- | --- | --- |
| `solari-cinematic-gateway` | `/solari-cinematic-gateway` | Tension, Golden Master, Evermore palette, then a board |
| `cinematic-storyboard` | `/cinematic-storyboard` | Solari shot ladder + PDF import |
| `cinematic-storyboard-export` | `/cinematic-storyboard-export` | JSON / CSV / director HTML / PDF / contact / Unity |

## Install in Grok Ask

1. Zip one skill folder (it must contain `SKILL.md` at the folder root).
2. Open [grok.com/skills](https://grok.com/skills) → Create / Upload skill.
3. Upload the zip. Enable it.
4. In **Ask**, type the slash command or describe the job.

Suite zips also ship from the Solari Board studio (`/skills`).

## Install in Grok Build

Copy the folders into `.grok/skills/` (project) or `~/.grok/skills/` (user).
